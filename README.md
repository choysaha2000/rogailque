Rogalique - это игра в жанре рогалик в двухмерном пространстве.

* Игрок передвигается по карте и убивает хищников. Всего в игре 3 уровня со своими уникальным типом врагов. 

Сюжет:

&nbsp;	Хищники слишком много на себя берут, отнимает всю непосильно добытую мясо травоядных и людей. Мясо старого льва пробудило в Вас силы сверххищника. Теперь пора вернуть должок!

Уничтожьте всех своих обидчиков. Перемещайтесь по ареалам их обитания и уничтожьте всех до единого. Станьте Королем саванны!



Управление:

&nbsp;	Перемещение по двухмерной карте: W - UP, S - DOWN, A - LEFT, D - RIGHT

&nbsp;	Атака - Кнопка F

&nbsp;	

Враги после уничтожение исчезают. 

После победы можете начать заново. 

Во время игры можете выйти в меню на паузы, позже вернуться на то же место.



Записи логгирование найдете в одноименном текстовом файле. Просто укажите в поисковике файл log.txt.
